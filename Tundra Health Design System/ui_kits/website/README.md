# Tundra marketing site — UI kit

A single-page marketing homepage built only from design-system components.

| File | Section |
| --- | --- |
| `SiteHeader.jsx` | Sticky translucent header, Logo, nav, primary CTA |
| `Hero.jsx` | Dotted + grained `Surface`, display-1 headline, source tags |
| `UseCases.jsx` | The four product use cases as a 2×2 Card grid |
| `AnalysisSection.jsx` | The analytics proof section — spend trend, fleet donut, vendor bars, SLA attainment table |
| `GraphSection.jsx` | Ink band — the provenance table that explains the device graph |
| `SiteFooter.jsx` | Cream CTA band plus link columns |

Copy in this kit paraphrases the brief supplied by the founder; the outcome figures
("up to 20%", "up to 60%") come from that brief and should be re-verified before real use.

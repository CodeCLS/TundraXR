One-line: The standard Tundra action control — one `primary` per view, `secondary` for everything else, `ghost` inside dense toolbars and table rows.

```jsx
<Button variant="primary" iconLeft="sparkles">Triage this call</Button>
<Button variant="secondary" size="sm">Export CSV</Button>
<Button variant="ghost" size="sm" iconRight="chevron-right">Full history</Button>
```

Variants: primary (ink on cream text), secondary (paper + hairline), ghost, accent (glacier — reserved for AI/agent actions), danger (rust). Sizes sm 28 / md 34 / lg 44.

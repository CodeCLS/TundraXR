One-line: A compact status marker for device state, SLA state and record provenance.

```jsx
<Badge tone="ok" dot>In service</Badge>
<Badge tone="warn" dot>PM overdue</Badge>
<Badge tone="down" dot>Down</Badge>
<Badge tone="info">Agent-generated</Badge>
```

Sentence case, never uppercase. Use `dot` for live device/asset state; omit it for classification labels.
